PROJECT · CAPSTONE

ROBOTICS · EDGE AI · MECHATRONICS

Edge-AI Pick-and-Place Robotic System with Material-Based Drop Height Control

Pick-and-place robots usually release every object from the same height, even though glass, wood, plastic and metal react very differently when dropped. This capstone project uses a Dobot Magician 4-axis arm controlled by a Raspberry Pi 5. The Pi identifies the object's material from a webcam image, on the device itself, and the arm releases the object from a height that suits that material. An HC-SR04 ultrasonic sensor below the gripper measures the release height.

How it works

  1. 01Webcam captures the object
  2. 02On-device model classifies the material
  3. 03Drop height looked up for that material
  4. 04Arm picks and moves to the release point
  5. 05Ultrasonic sensor checks height, object released

My contribution

  • Built and tested the basic pick-and-place operation on the Dobot Magician
  • Integrated the Raspberry Pi with the Dobot and wrote robot-control commands from the Pi terminal
  • Collected and prepared the image dataset across the four material classes
  • Trained the image-based material classification model that drives drop-height selection

Results

0.95mAP@0.5 (validation)
~11,300Images in dataset
~92%Drop accuracy of height control
